# BeamNG.Drive - 284160 Multiplayer mod tutorial

1. Launch the game in single player first, play for a bit.
2. Then next step is go to game installation folder, launch `BeamMP-Launcher.exe`
3. It will do some installation for Multiplayer mod.
4. Then the normal BeamNG.drive game launcher will show up.
5. Play the game! Enjoy!
