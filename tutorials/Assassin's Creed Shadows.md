# A guide to play Assassin's Creed Shadow
> ⚠️ **Warning:** If you ever use Hypervisor version of the game, please go to Steam Unlock Onennabe -> Library -> REMOVE HYPERVISOR PATCH first

## **PLEASE MAKE SURE TO TURN ON SMART APPLY BY HEADING TO TOOLS > GAME AUTO UPDATE + REAL TIME PROTECTION IS DISABLED**

1. In Steam Unlock Onennabe click `Unlock Game`
2. Install the game in Steam
3. Then in Steam Unlock Onennabe -> Library -> click on `Bypass Game`
4. Press the `Bypass Game` again after its added to exclusion
5. Play the game from Steam Unlock > Choose .exe.
