# 🎮 Ultimate Windows Emulator Directory

### 🕹️ Multi-System & Arcades
* [RetroArch](<https://www.retroarch.com/>) — Unified frontend running cores for 8-bit through 32-bit consoles.
* [MAME](<https://www.mamedev.org/>) — Reference arcade & vintage computer hardware emulator.
* [Ares](<https://ares-emu.net/>) — High-accuracy multi-system emulator (cycle-accurate).
* [Mednafen](<https://mednafen.github.io/>) — Multi-system CLI emulator (PS1, Saturn, GBA, PC Engine).

### 🟦 Sony PlayStation

**Classic & Handhelds:**
* **PS1:** [DuckStation](<https://github.com/stenzek/duckstation>) — Upscaling, PGXP wobble fix, modern UI.
* **PS2:** [PCSX2](<https://pcsx2.net/>) — Vulkan/DX12, widescreen, 60fps patches.
* **PS3:** [RPCS3](<https://rpcs3.net/>) — High compatibility, 4K/60FPS upscaling.
* **PSP:** [PPSSPP](<https://www.ppsspp.org/>) — Fast, lightweight, 4K rendering.
* **PS Vita:** [Vita3K](<https://vita3k.org/>) — Experimental PS Vita emulator.

**PS4 (Active Development):**
* [shadPS4](<https://shadps4.net/>) — Leading PS4 emulator; boots 3D commercial titles (*Bloodborne*).
* [fpPS4](<https://github.com/red-prig/fpPS4>) — Pascal-based layer; runs hundreds of 2D & indie games.
* [Kyty](<https://github.com/Inori/Kyty>) — Early experimental PS4/PS5 compatibility layer.

**⚠️ PS5 (Early Research & Experimental):**
> *PS5 emulation is in its research infancy. Only homebrew, menus, and select light 2D software boot. Beware of fake .exe installer scams online.*
* [KytyPS5](<https://github.com/>) — Community branch targeting PS5 graphics shaders & ELF booting.
* [SharpEmu](<https://github.com/>) — C# open-source PS5 emulator with compatibility tracking.
* [RPCSX](<https://github.com/>) — Experimental low-level PS4/PS5 layer by RPCS3 developers.
* [Prosperity](<https://github.com/>) — Open-source low-level PS4/PS5 reverse-engineering emulator.

### 📲 PC-on-Mobile Translation & Compatibility Layers
> *Tools running x86/x64 Windows PC games on Android ARM devices via Wine, Box64/FEX, and DXVK.*
* [Winlator](<https://github.com/brunodev85/winlator>) — Full Wine/Box86/Box64 container layer to run PC games on Android.
* [Mobox](<https://github.com/olegos2/mobox>) — High-performance Termux-based PC gaming translation layer.
* [Horizon-Emu](<https://github.com/>) — Lightweight Android container for running DirectX/Vulkan PC titles.
* [GameHub](<https://github.com/tkashkin/GameHub>) — Open-source unified game library aggregator and frontend.
* [DroidDeck](<https://github.com/>) — Automated emulator configuration and directory hub for Android handhelds.
*  [Bannerlator](<https://github.com/The412Banner/Bannerlator>) — Shortcut and banner APK generator for Winlator containers to launch PC games directly from Android home screens.
