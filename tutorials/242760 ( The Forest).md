# 242760 ( The Forest)

1. Unlock the game from SUO.

2. Download and install as usual.

3. Temporarily disable your antivirus, especially Real-time Protection:
*Open Windows Security
*Go to Virus & threat protection
*Click Manage settings
*Turn Real-time Protection OFF

4. Apply the online patch.

5. Verify integrity of game files at steam at game properties.

6. Go to your game installation folder:
*Steam → steamapps → common → The Forest
*Locate TheForest32.exe
*Right-click TheForest32.exe → Properties → Compatibility
Tick "Run this program as an administrator"
*Click Apply → OK

7. Launch the game from Steam.
